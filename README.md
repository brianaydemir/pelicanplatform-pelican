[Pelican](https://pelicanplatform.org/) is open-source software for building data federations. A federation serves objects from many data repositories through one namespace, whatever storage each repository uses. The [Open Science Data Federation](https://osg-htc.org/services/osdf/) runs on Pelican.

This repository holds the source for the Pelican client and servers, the servers' web UI, and the Pelican documentation.

## Documentation

The [Pelican documentation](https://docs.pelicanplatform.org/) explains how to install, configure, and run Pelican. Its [Getting Started](https://docs.pelicanplatform.org/getting-started) page points users and administrators to the pages for their tasks.

## Contributing

The [contributor guide](https://github.com/PelicanPlatform/pelican/blob/main/CONTRIBUTING.md) explains how to build Pelican from source, test it, and propose changes. To report a security vulnerability, follow the [security policy](https://github.com/PelicanPlatform/pelican/blob/main/SECURITY.md).
